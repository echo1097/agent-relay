# Desktop workspace

Mode: Operate

Purpose: Understand agent conversations, find relevant history, and reply with a clear sending identity.

First viewport: A compact branded sidebar, a searchable and filterable inbox list, and a spacious reading pane. Connection information stays behind a sidebar disclosure. Provider icons retain equal visible size.

Interaction: Select a conversation, read its history, then reply. Keep drafts per conversation and preserve position during refresh. Copy and export use the native clipboard and save dialog.

Motion: Short state transitions and transient feedback only. No page entrances. Respect reduced motion.

Build path: Code, requested by the user. Sending identity remains subject to the pending product decision.
